# Case Studies

Written accounts of running growth with agents. Real work, real numbers,
anonymized.

## Rules

**Anonymization.** No brand names. No absolute revenue. No account IDs. No
screenshots with identifiable data. Percentages, ratios, and indexed values only
(index the baseline to 100).

**No invented numbers.** Every figure traces to real data. Anything unsourced is
marked `[TBD]` and stays visibly marked until it's real. A plausible-looking fake
number is worse than an obvious gap.

**Failure is required.** Every case study includes what went wrong. A case study
without it is marketing, not evidence — and readers can tell.
