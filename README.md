# The Weekly Loop

**Running paid growth with AI agents instead of headcount — the system, the
guardrails, and the things that broke.**

I'm a performance marketer. For the last stretch I've been running paid
acquisition for a portfolio of e-commerce brands — Meta, Google, TikTok, GA4 —
and progressively handing the repeatable parts of that job to agents I build
myself.

The name is the thesis. Growth has a weekly loop: pull the numbers, find what
moved, decide what to change, change it, write it up. That loop is where most of
a marketer's week goes, and it is the part a well-designed agent system can
actually take. This repo is that handover, in the open.

## Why this exists

Most "AI marketing" content is a list of tools. This is the opposite: a record of
one practitioner rebuilding their own job around agents, with the failures
included.

Three things I care about here:

1. **The system, not the prompt.** A prompt that works once is a party trick. A
   skill with defined inputs, guardrails, and a known failure mode is
   infrastructure.
2. **Judgment is the job.** Agents produce; humans decide what's true and what
   ships. The interesting work is designing where that line sits.
3. **Show the breakage.** Every case study here includes what the agent got wrong.
