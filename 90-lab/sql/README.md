# SQL Practice

Weeks 5-6 of the roadmap. The rule: no abstract exercises. Every query answers a
real question about real data I actually care about.

Save every query, even the wrong ones. The wrong ones are the evidence of
learning and they make a good post later.

## Target capability by end of Week 6

Answer this unaided, in one query:

> "What is the D30 retention of last month's acquisition cohort?"

Requires: CTEs, a self-join or window function, date truncation, and knowing what
retention actually means in the underlying data model.
